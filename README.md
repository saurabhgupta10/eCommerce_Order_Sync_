# QA Engineering Portfolio Project: E-Commerce Order Sync Engine

This repository demonstrates practical end-to-end QA methodologies including Test Case Design, Boundary Value Analysis, API Postman Testing, SQL Database Validation, and AI-assisted Test Engineering.

## Repository Contents
- `/test-cases`: Test suite covering Functional, EP, BVA, and Edge Case scenarios.
- `/api-tests`: Postman collection for REST API request and payload validation.
- `/sql-validation`: SQL JOIN scripts to verify backend database data integrity.

## AI-Assisted Testing Workflow
- **Test Generation:** Utilized Claude/ChatGPT prompts to uncover hidden edge cases and race condition scenarios.
- **Verification:** Manually validated AI-generated edge cases against technical business logic to avoid false positives.
